Cryptographic Safety Guarantees

Key Manager policy enforcement rules
  • No Plain Secret Exposure: Secret key bytes are never rendered in HTML, logged to console, or passed over unauthenticated endpoints.
  • Per-File Nonce Uniqueness: AES-256-GCM generates a cryptographically distinct 96-bit nonce for each individual file transfer.
  • State Invalidation: Once a key reaches its maximum usage limit or TTL expires, it cannot be used for new encryptions.
  • Manual Revocation: Administrators can immediately revoke compromised or obsolete keys.

Architecture & Theoretical Foundations

Quantum Key Distribution, Cryptographic Bounds, and Simulation Assumptions
Academic & Experimental Disclaimer: This platform performs a software simulation of the BB84 protocol using Qiskit Aer statevector circuits. It simulates quantum states, basis reconciliation, and channel disturbances. It does not replace physical fiber-optic photon detectors or hardware quantum random number generators.

1. BB84 Quantum Key Distribution

Alice encodes random bits into single photon polarization states chosen from two conjugate bases: rectilinear (+) with {|0>, |1>} and diagonal (x) with {|+>, |->}. Bob independently measures in randomly chosen bases. Because conjugate bases cannot be simultaneously measured without quantum disturbance (Heisenberg uncertainty and No-Cloning Theorem), an eavesdropper (Eve) who intercepts and resends qubits introduces a characteristic ~25% error rate on matching bases.

2. QBER Quality Analysis

Alice and Bob publicly compare a sample fraction of their sifted bits to estimate the Quantum Bit Error Rate (QBER). The bits revealed during error estimation are discarded. If QBER ≤ 11% (the theoretical threshold against general coherent attacks), the remaining secret bits undergo privacy amplification and key derivation.

3. Authenticated AES-256-GCM Encryption

Files are encrypted using AES-256 in Galois/Counter Mode (GCM). AES-GCM provides both confidentiality and data authenticity with a 128-bit authentication tag, strictly preventing undetected tampering or replay attacks. Each file transfer generates an independent 96-bit cryptographic nonce.
